# Giant Egg Implementation Plan (Build Step 7)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When the boss dies, a giant egg drops in the arena after a 3 s countdown. The top 3 damage dealers get a 2 s head start; then anyone can grab it. The carrier is slowed and glows; one hit from another player, death, leaving or falling makes them drop it. Bringing it to your own base's delivery pad adds a `Stage1_Giant` egg to your eggs. Undelivered eggs return to the arena once at 3 min and vanish at 5 min.

**Architecture:** Rules are pure, unit-tested modules in `server/Logic`: `GiantEggRules` (pickup checks, timeouts, pad check) and `CarryCheck` (carrier speed anti-cheat, last ground position). `GiantEggService` owns the egg parts, the server-side ProximityPrompt, carrying, dropping, delivery and the `GiantEggState` broadcasts. `CombatService` gains player-vs-carrier hits. Client: `GiantEggController` shows a status banner; `CombatController` skips the dodge dash while carrying.

**Tech Stack:** Luau, Roblox Studio, Rojo 7.7.1, Roblox Studio MCP (`execute_luau`, `start_stop_play`, `get_console_output`, `screen_capture`).

**Spec:** [docs/specs/2026-10-10-architecture-design.md](../../specs/2026-10-10-architecture-design.md) (section 4 GiantEggService and tags, 7 `GiantEggState`, 8 player attacks on the carrier, 9 step 4, 10 giant egg, 16 player leaves). Design: [big-egg.md](../../../Steal%20a%20boss%20fight/design/big-egg.md), decision 3.

## Decisions this plan makes (not in the spec)

1. **Branch:** `feat/giant-egg` from `main`.
2. **Several eggs at once.** The boss respawns after 60 s but an egg lives 5 min, so each kill spawns its own egg, up to `GiantEgg.maxActive = 3`. A kill at the cap spawns nothing (log line only). Egg ids are `"g1"`, `"g2"`, … per server.
3. **Timers start when the egg lands** (`readyAt = kill time + countdown`): head start ends at `readyAt + 2`, return at `readyAt + 180`, despawn at `readyAt + 300`. A return also happens while carried (the carrier loses it). Returned eggs get no new head start.
4. **Hitting a carrier:** `Attack` hits the nearest *other* player who carries an egg within `hit.range + rangeTolerance`, instead of the boss. It deals `GiantEgg.carrierHitDamage = 10` HP and drops the egg. Non-carriers are never damaged by players.
5. **Drop position** is always the carrier's last *grounded*, speed-valid position (`CarryCheck`), so a carrier who falls off the map or is caught speeding drops it back on solid ground. The egg lands anchored, 3 studs above that point.
6. **Speed check:** sampled every `speedSampleSeconds = 0.25`; horizontal distance must be ≤ `(Training.carryWalkSpeed + speedTolerance) × elapsed + speedSlack` (`speedTolerance = 4`, `speedSlack = 4`). The first `speedGraceSeconds = 0.5` after pickup only record positions (walk speed replication delay). Vertical movement is not checked.
7. **Dodge while carrying:** the claim and i-frames still work, the dash doesn't (it would exceed carry speed). Client-side, via the player attribute `CarryingGiantEgg`.
8. **Delivery** is checked on the heartbeat (root inside the pad's footprint, up to 8 studs above it), only on *entering* the pad. If `EggService:Grant` fails (storage full, which already sends a Notice), the player keeps carrying.
9. **Walk speed:** pickup saves the humanoid's `WalkSpeed` and sets `Training.carryWalkSpeed`; dropping restores it. Build step 10 (training) must not raise walk speed while `CarryingGiantEgg` is true.
10. **Stands disabled while carrying:** stands don't fight yet. `GiantEggService:IsCarrying(player)` and the `CarryingGiantEgg` attribute are the hook; build step 8 must check them.
11. **Visuals (placeholders):** egg = a 6-stud gold Neon ball (`Shape = Ball`, named `GiantEgg_<id>`) in `Workspace.GiantEggs`, with an AlwaysOnTop BillboardGui "GIANT EGG" and a ProximityPrompt (`ActionText = "Grab"`, `HoldDuration = 0.3`, `MaxActivationDistance = pickupRange`). While carried it is welded above the carrier's head (Massless, no collision) and the character gets a gold `Highlight` with `DepthMode = AlwaysOnTop`, visible to everyone.
12. **`GiantEggState` payload** (flat table): `{ id, phase, endsAt?, carrierName?, carrierUserId? }`, phase one of `Countdown`, `HeadStart`, `Free`, `Carried`, `Returned`, `Delivered`, `Despawned`. `endsAt` (server clock) only for `Countdown` and `HeadStart`.
13. **Not in this step:** minimap marker, team escorts (no special rules: anyone can hit the carrier, allies included), boss hits on the carrier (they don't drop it), effects polish (step 12).

## Global Constraints

- The server decides who holds each egg and who gets the `Stage1_Giant` egg. Pickup goes only through the server-side ProximityPrompt (no remote), re-checked with `GiantEggRules.canPickUp`.
- Only DataService writes player data; giving the egg goes through `EggService:Grant(player, GiantEgg.eggId)`.
- Pure modules (`server/Logic`) never call `game:GetService`.
- Every number lives in `shared/Config/GiantEgg.luau` (or existing `Training.carryWalkSpeed`, `Combat.rangeTolerance`), never as a literal in a service.

## Review Focus

1. **Carrier dies, respawns or leaves mid-carry** → the egg drops at their last ground spot and stays grabbable; it never disappears with them. Play-check in Task 3.
2. **Lag stutter** (one 0.6 s sample gap at normal carry speed) → no false drop; **teleport** (40 studs in 0.25 s) → drop. Tests in Task 1 (`CarryCheck`).
3. **Two players grab in the same frame, or the carrier grabs a second egg** → one carrier per egg, one egg per carrier. Tests in Task 1 (`canPickUp` reasons `"carried"`, `"already carrying"`).
4. **Carrier falls off the map** → egg lands at the last grounded position, not mid-air or in the void. Test in Task 1 (`lastValid` ignores airborne samples), play-check in Task 3.
5. **Delivery with full egg storage** → one Notice per pad entry, egg stays carried and is not lost. Play-check in Task 2.

**Files:**

**Interfaces:**
- Produces `Config/GiantEgg`: `{ eggId = "Stage1_Giant", countdownSeconds = 3, headStartSeconds = 2, headStartCount = 3, pickupRange = 10, regrabCooldown = 1, returnAfterSeconds = 180, despawnAfterSeconds = 300, maxActive = 3, carrierHitDamage = 10, speedSampleSeconds = 0.25, speedTolerance = 4, speedSlack = 4, speedGraceSeconds = 0.5, padHeight = 8, announceRarity = "Mythic", size = 6 }`.
- Produces `type EggState = { readyAt: number, headStartUntil: number, top: { [number]: boolean }, carrierUserId: number?, lastCarrierUserId: number?, regrabUntil: number, returned: boolean }`.
- Produces `GiantEggRules.canPickUp(egg: EggState, userId: number, carryingOther: boolean, distance: number, now: number, cfg): (boolean, string?)`. Reasons, checked in this order: `"not ready"` (`now < readyAt`), `"carried"`, `"already carrying"`, `"too far"` (`distance > pickupRange + 2`), `"head start"` (`now < headStartUntil` and not `top[userId]`), `"cooldown"` (`userId == lastCarrierUserId` and `now < regrabUntil`).
- Produces `GiantEggRules.timeoutAction(egg: EggState, now: number, cfg): "despawn" | "return" | nil`: despawn at `readyAt + despawnAfterSeconds`; otherwise return at `readyAt + returnAfterSeconds` if not `returned`.
- Produces `GiantEggRules.onPad(pos: Vector3, padCFrame: CFrame, padSize: Vector3, height: number): boolean`: `pos` in pad-local space has `|x| ≤ size.X/2`, `|z| ≤ size.Z/2`, and `0 ≤ y − size.Y/2 ≤ height`.
- Produces `CarryCheck.new(pos: Vector3, t: number, cfg): State` (`lastPos = lastValid = pos`, `lastT = t`, `graceUntil = t + speedGraceSeconds`) and `CarryCheck.step(state, pos: Vector3, t: number, grounded: boolean, speed: number, cfg): boolean`. Returns true and does nothing if `t − lastT < speedSampleSeconds`. Before `graceUntil`, only records (`lastPos`, `lastT`, and `lastValid` if grounded) and returns true. Otherwise compares horizontal distance to decision 6: too far → return false, state unchanged; else record as above and return true. `state.lastValid` is the drop position.

- Produces `GiantEggService:GetEggs(): { [string]: Rec }` where `Rec = EggState & { id: string, part: BasePart, carrier: Player? }` (for play-test scripts).
- Produces `GiantEggService:TryPickUp(player, eggId: string): (boolean, string?)` — the prompt's `Triggered` calls it. On a failed check, Notice: `"head start"` → `"Top damage dealers grab first!"`, `"cooldown"` → `"Wait a moment before grabbing it again."`, `"already carrying"` → `"You're already carrying a Giant Egg."`; others silent. On success: weld to the character, set carry speed, `Highlight`, attribute `CarryingGiantEgg = true`, disable prompt, start a `CarryCheck`, hook `Humanoid.Died` and `CharacterRemoving` to `Drop`, `AnnounceService:All(name .. " grabbed the Giant Egg!", announceRarity)`, broadcast `Carried`.
- Produces `GiantEggService:Drop(player, reason: string)`: no-op if not carrying. Unweld, anchor at `lastValid + (0, 3, 0)`, restore walk speed, remove highlight and attribute, set `lastCarrierUserId`/`regrabUntil = now + regrabCooldown`, re-enable prompt, broadcast `Free`. Reasons used: `"hit"`, `"died"`, `"left"`, `"speed"`, `"returned"`.
- Produces `GiantEggService:IsCarrying(player): boolean` (decision 10).
- Produces `GiantEggService:CarrierInReach(attacker: Player, position: Vector3, reach: number): Player?`: nearest other carrier whose root is within `reach`.
- Behaviour: on `Defeated`, if fewer than `maxActive` eggs, announce `"A Giant Egg is dropping in the arena!"`, broadcast `Countdown` (`endsAt = readyAt`), create the part at the spawn after the countdown, broadcast `HeadStart` (`endsAt = headStartUntil`), then `Free` at `headStartUntil`. One `Heartbeat` connection: per carried egg run `CarryCheck.step` (false → `Drop(player, "speed")`) and the pad entry check (decision 8; success → announce `"<name> delivered the Giant Egg!"`, broadcast `Delivered`, destroy egg); per egg run `timeoutAction` (return → drop if carried, move to spawn, `returned = true`, broadcast `Returned` then `Free`; despawn → drop if carried, destroy, broadcast `Despawned`). `PlayerRemoving` → `Drop(player, "left")`.
