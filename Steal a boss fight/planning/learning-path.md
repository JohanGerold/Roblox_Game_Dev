# Learning Path

Starting point (2026-10-09): **zero experience** in Roblox Studio, Luau scripting and 3D modelling, ready to learn.

## The idea

Don't learn everything first, and don't start with the full game. Build tiny practice projects that are each a piece of the real game, so nothing is wasted.

## Stages

1. **Roblox Studio basics**: move around, place parts, test play, publish a private place. Use the official Roblox Creator Hub docs (create.roblox.com/docs).
2. **Luau basics**: variables, functions, tables, events. Server scripts vs local (client) scripts.
3. **Practice project: simple tycoon**. A button that gives money per second, saved with DataStores. (Teaches the [economy](../design/progression-and-economy.md).)
4. **Practice project: carry an object home**. Pick up a part, carry it, drop it when hit, deliver to your base. (Teaches the [giant egg](../design/big-egg.md).)
5. **Practice project: one enemy that attacks you**, and a dodge. (Teaches [combat](../design/combat.md).)
6. **Client–server communication**: RemoteEvents, and why the server must check everything (exploiters).
7. **Art and animation**: decide between learning Blender, buying licensed models, or commissioning artists. Learn the Roblox Animation Editor for attacks.
8. Start [V1 build order](v1-scope.md) step 1.

## Art options

| Option | Pros | Cons |
|---|---|---|
| Learn Blender | Free, full control | Slow at first; characters and bosses are hard |
| Buy licensed models | Fast | Must check licence; others may use the same models |
| Commission artists | Quality | Costs money |

## Safety

- Only use Creator Store models from trusted creators, and read every script inside (hidden backdoors are common).
- Never use "uncopylocked" leaked copies of other games.
