# Steal a Boss Fight

Roblox game. Design notes: [Obsidian vault](Steal%20a%20boss%20fight/INDEX.md).

## Working on it

1. Open the place in Roblox Studio.
2. In a terminal here, run `rojo serve`.
3. In Studio: Plugins tab → Rojo → Connect.

Code lives in `src/` and syncs into Studio live. The map (parts, terrain, lighting) is built in Studio and saved to Roblox, not to this folder.

Tools are pinned in `rokit.toml` (install with `rokit install`).
